# Scoban Insights website

A static, GitHub Pages-ready website for the Scoban Insights TikTok developer application.

## Before publishing

The legal pages have been completed with the supplied operator, contact, address, jurisdiction, and court information. The policies are a professional starting point, not legal advice. Have them reviewed by someone familiar with Elephant Pal Sdn Bhd's actual data practices and Malaysian law.

## Publish with GitHub Pages

1. Create a public GitHub repository (for example, `scoban-insights`).
2. Upload the files in this folder to the repository root. `index.html` must remain at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait a few minutes for GitHub to publish the site.

For a repository named `scoban-insights` under the account `Denji88`, the expected addresses are:

- Website: `https://denji88.github.io/scoban-insights/`
- Privacy Policy: `https://denji88.github.io/scoban-insights/privacy.html`
- Terms of Service: `https://denji88.github.io/scoban-insights/terms.html`

Use the Privacy Policy and Terms of Service addresses in the TikTok developer application form.

## Files

- `index.html` — public landing page
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `style.css` — shared design and responsive layout

The “SI” app mark is built entirely with HTML and CSS, so no separate image asset or external image hosting is required.
